## I break things so companies don't have to find out the hard way

Hi I'm Keerthan — a penetration tester who's spent the last year getting paid to think like an attacker. Ten-plus client engagements later, across web apps, networks, and APIs, I've learned that most breaches don't come from zero-days. They come from the boring stuff: a reused password, a misconfigured endpoint, an IDOR nobody bothered to check. Finding that boring stuff before someone with worse intentions does — that's the job.

I currently work through VAPT engagements professionally, and outside of client work I build my own vulnerable machines from scratch (deliberately broken SSH, FTP, MySQL, Apache — the works) just to have a sandbox nobody else has already solved. I also trained a Random Forest classifier to catch malware hiding in IoT firmware, hit 92% accuracy, and got it published — because sometimes the interesting problems aren't on the OWASP Top 10.

This blog is where the CTF machines live. Not polished tutorials — actual notes from actual attempts, including the wrong turns.

### The credentials, if you need them
CEH v12 · eJPT v2 · CRTA (Red Team) · CNSP · API Penetration Tester — currently pursuing MSc in Cyber Security at the University of Hertfordshire.

### What I'm actually good at
Web app pentesting, API security, Active Directory attacks, and turning a five-line nmap scan into a full compromise chain.

### Tools of choice
Burp Suite, Nmap, Metasploit, Wireshark, SQLmap, Hydra — plus whatever the box forces me to learn on the spot.
